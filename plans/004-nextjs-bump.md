## Why this matters

The Next.js showcase site (`docs/`) is pinned to `next@16.3.2`, which falls inside the affected range of multiple critical advisories published against Next 16.x, including unauthenticated RCE classes (Windows-hosted RCE advisory GHSA-p293-qw3h-jr36, RCE via image optimization, RCE in `next/og` ImageResponse), plus high-severity SSRF and DoS. The site is deployed to GitHub Pages via `.github/workflows/pages.yml` and the Windows-hosted RCE advisory matches this repo's environment. `npm audit --omit=dev` reports critical with `fixAvailable: next@16.4.6`. This is a patch-minor bump inside 16.x, not a migration, but Next patch releases occasionally change build behavior — the static export must be re-verified.
